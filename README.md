# C Logic Building — 180 Exercises

A collection of 180 C programming exercises created for a logic-building class. The repository is intended to document practice with programming fundamentals and provide a clear reference for students and instructors.

## About

The exercises focus on turning a problem into a step-by-step solution and expressing that solution in C. Each program is part of a broader practice set for developing problem-solving and programming skills.

## Getting started

You will need a C compiler, such as GCC or Clang. To compile an exercise, replace `<source_file>.c` with its filename:

```sh
gcc <source_file>.c -o exercise
```

Run the compiled program with:

```sh
./exercise
```

On Windows, run `exercise.exe` instead.
